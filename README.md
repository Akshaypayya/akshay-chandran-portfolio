# Akshay Chandran Portfolio

Portfolio for Akshay Chandran — Full-Stack Developer | Flutter & Node.js Specialist.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
